# Healthcare Pharm Sales & Profit Analysis | Excel Dashboard

## 📊 Project Overview

This project presents an interactive Healthcare Pharm Sales and Profit Analysis Dashboard developed using Microsoft Excel.

The dashboard provides a comprehensive view of sales performance, purchase trends, profitability, product performance, and category-wise sales. It also allows users to analyze business performance based on Financial Year (FY) and Staff.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization
- Slicers

## 📌 Key Performance Indicators (KPIs)

The dashboard includes the following key metrics:

- Total Sales: 7,151K
- Total Purchase: 3,595K
- GST Paid: 411K
- Total Profit: 3,967K
- Profit Margin: 55%

## 📈 Dashboard Analysis

### 1. Monthly Sales Analysis

The monthly sales chart helps identify sales trends throughout the year and highlights months with higher and lower sales performance.

### 2. Category-wise Sales

The category analysis shows sales distribution across different pharmaceutical categories, including:

- Respiratory
- Supplement
- Antibiotic
- Others

### 3. Quarter-wise Sales

Quarterly sales analysis compares business performance across:

- Q1
- Q2
- Q3
- Q4

### 4. Top 5 Products by Sales

The dashboard identifies the top-performing products based on sales value.

The top products include:

- Amoxicillin 500mg
- Azithromycin 500mg
- Calcium + D3
- Cough Syrup 100ml
- Salbutamol Inhaler

### 5. Financial Year Analysis

The FY slicer allows users to filter the dashboard based on different financial years.

### 6. Staff Analysis
